See what changes before you deploy

InfraLens turns a Pulumi or AWS CDK preview into a report you can explore in your browser. See what will be added, updated, or removed, follow connections between services, and estimate what your changes could cost.

Run it in your project

Install from GitHub

Run one of these commands from your project directory. It opens the report in your browser without deploying anything. You can share the HTML file or open it offline.

Pulumi preview

InfraLens preview --provider=pulumi

AWS CDK changes

InfraLens preview --provider=aws-cdk
