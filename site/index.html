Visualize Pulumi and AWS CDK changes

InfraLens is an open-source CLI that turns infrastructure previews into interactive HTML reports. Review changes and trace connections in a single file you can open offline.

Run it in your project

Install from GitHub

Run the command for your provider from the project directory. It writes infralens.html and opens it in your browser.

Pulumi preview

InfraLens preview --provider=pulumi

AWS CDK changes

InfraLens preview --provider=aws-cdk

Already have an export or a synthesized template? Render saved infrastructure data.

In the report

Check what changes

Compare before and after views. Filter additions, updates and removals.

Trace a connection

Follow events and configuration references. Select a connection to inspect its evidence.

Share the Markdown guide so an agent can generate a report and query specific resources or changes.
